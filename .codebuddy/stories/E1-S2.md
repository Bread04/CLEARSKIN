## Implementation Notes

- Demo mode uses `DEMO_USER_ID = 'demo-user-001'` (defined in `lib/utils/demo.ts`)
- A `users` row for demo-user-001 must be inserted in `seed.sql` so FK constraints on `user_profiles` and `log_entries` are satisfied
- `lib/types/database.ts` already complete from E1-S1 — no changes needed
- `lib/supabase/server.ts` uses `@supabase/ssr` `createServerClient` with Next.js cookies
- `lib/supabase/client.ts` uses `@supabase/ssr` `createBrowserClient`
- `pg_trgm` is enabled in migration via `CREATE EXTENSION IF NOT EXISTS pg_trgm`

### Patch (fix required)

- [x] [Review][Patch] F1 — DEMO_USER_ID mismatch: `demo.ts` exports `"demo-user-001"` but `seed.sql` inserts `"demo-user-001-0000-0000-000000000000"` — ALL demo queries return empty rows → **Fixed**: `DEMO_USER_ID` updated to `"demo-user-001-0000-0000-000000000000"` in `lib/utils/demo.ts`
- [x] [Review][Patch] F2 — `hawker_dishes` seed has no `ON CONFLICT` clause; re-running seed duplicates all 85 rows → **Fixed**: Added `UNIQUE (name_en)` constraint + `ON CONFLICT (name_en) DO UPDATE` upsert in `seed.sql`
- [x] [Review][Patch] F3 — `user_profiles` missing `FOR INSERT` RLS policy; onboarding INSERT silently blocked → **Fixed**: Added `"Users can insert own profile"` policy in migration
- [x] [Review][Patch] F12 — `users` table missing `FOR INSERT` and `FOR UPDATE` RLS policies → **Fixed**: Added `"Users can insert own row"` and `"Users can update own row"` policies in migration
- [x] [Review][Patch] F4 — `log_entries` missing `FOR DELETE` RLS policy → **Fixed**: Added `"Users can delete own log entries"` policy in migration
- [x] [Review][Patch] F5 — `DbUser.email` typed as `string` but SQL column is nullable `text` → **Fixed**: Changed to `email: string | null` in `lib/types/database.ts`
- [x] [Review][Patch] F6 — `user_profiles.updated_at` has no `BEFORE UPDATE` trigger → **Fixed**: Added `set_updated_at()` function + `trg_user_profiles_updated_at` trigger in migration
- [x] [Review][Patch] F7 — `createClient()` does not validate `SUPABASE_SERVICE_ROLE_KEY` at startup → **Fixed**: Early throw with clear message added in `lib/supabase/server.ts`; function made `async`
- [x] [Review][Patch] F8 — `hawker_dishes.category` has no `CHECK` constraint → **Fixed**: Added `CHECK (category IN ('noodles','rice','soup','grilled','fried','dessert','drinks','bread_pastry','other'))` in migration
- [x] [Review][Patch] F10 — `aliases` column has no GIN trgm index → **Fixed**: Added `idx_hawker_dishes_aliases_trgm` GIN index in migration
- [x] [Review][Patch] F11 — `server.ts` calls `cookies()` synchronously; Next.js 15 requires `await` → **Fixed**: `createClient()` made `async`, `await cookies()` in `lib/supabase/server.ts`
- [x] [Review][Patch] F13 — `streak` has no `CHECK (streak >= 0)` constraint → **Fixed**: Added `CHECK (streak >= 0)` to column definition in migration
